# TextUtils - React Text Utility App

TextUtils is a simple React-based web application that helps users perform basic text operations like converting text case, removing extra spaces, clearing text, and analyzing word/character count. It also includes a Dark Mode feature for better user experience.

---

## 🚀 Features

- Convert text to UPPERCASE
- Convert text to lowercase
- Clear text instantly
- Remove extra spaces from text
- Word and character count analysis
- Estimated reading time
- Dark Mode / Light Mode toggle
- Responsive UI using Bootstrap

---

## 🛠️ Tech Stack

- React.js (Frontend Library)
- JavaScript (Logic)
- HTML5 (Structure)
- CSS3 (Styling)
- Bootstrap 5 (UI Components)

## 2. Move into project folder
cd textutils

## 3. Install dependencies
npm install

## 4. Start development server
npm start
